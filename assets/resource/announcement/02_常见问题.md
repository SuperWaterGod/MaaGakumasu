# 常见问题

Q: 为什么在培育过程中会一直点击左上角？

A: 请参考文档 [提问与反馈指南](https://github.com/SuperWaterGod/MaaGakumasu/blob/main/docs/zh_cn/%E6%8F%90%E9%97%AE%E4%B8%8E%E5%8F%8D%E9%A6%88%E6%8C%87%E5%8D%97.md) 中的描述自查

Q: 为什么自动培育开始任务后半分钟会自动结束培育？

A: 参考插件版汉化官网[说明](https://www.gakumas.cn/):

`使用 MaaGakumasu 前，请在 Localify / 插件控制台中关闭 替换贴图 或贴图替换资源相关功能；需要正常游玩汉化贴图时再重新开启。`

Q: 遇到卡住、报错或识别异常时如何反馈？

A: 请优先保存 `debug\maa.log` 并附带截图，参考 [提问与反馈指南](https://github.com/SuperWaterGod/MaaGakumasu/blob/main/docs/zh_cn/%E6%8F%90%E9%97%AE%E4%B8%8E%E5%8F%8D%E9%A6%88%E6%8C%87%E5%8D%97.md) 描述问题（模拟器类型、分辨率、系统平台、游戏版本、是否 DMM/插件版汉化）；无法自行解决时可提交 GitHub Issues 或加入 QQ 群反馈。
