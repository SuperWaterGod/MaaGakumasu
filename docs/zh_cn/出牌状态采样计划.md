# 出牌状态采样计划

当前目标是识别对局状态，现阶段不要求六七种流派各跑一次。按缺失机制挑代表样本，已在其他流派局面中出现的通用图标先复用；缺少关键机制的方向再补一轮代表性培育。以后验证策略时，希望主要流派都有代表样本；一次培育不等于证明识别稳定，也不能证明策略有高分能力。

## 阶段结论（2026-10-13）

第一轮基础对局状态采样可以收尾：理性好印象/干劲、感性好调/集中、非凡冰火/全力都有代表样本，已能读取常用 HUD、可见 Buff 与部分姿态机制。当前登记 19 张绿幕模板，包含 13 个 Buff 图标变体、4 个姿态和 2 个非凡预告图标。采样足以继续开发，不代表所有状态、所有偶像或所有剧本都已识别完整。

仍需用现有截图补感性/理性指针、部分百分比修正、专属/P 道具触发、剩余出牌次数、保留牌身份和动画遮挡。本人分数的几何定位目前以日文 NIA 样本验证为主；初等其他布局尚未单独验证。`buffs_complete` 为 `false`，`game_action_confirmed` 为未知，所以这批数据不能直接当作完整、可信的强化学习轨迹。

“整次培育会话与路线候选采集”已接入 Agent：会话跨出牌调用及中断分段关联，路线节点保存候选原图、选择输入、后续观测和结算证据；后台 OCR 与整次培育报告已通过本地及原生内存控制器检查。2026-10-15 的完整 NIA 实测从 `ProduceEntryNIA` 建立会话，正常结算并返回主页；19 页共 69 个奖励候选记录齐全，原选择恢复核验和领取点击均通过，事件零丢弃、关联零缺口、后台识别零错误。67 项效果使用库默认值，2 项保留 OCR 原文待核对；这些记录不代表实际获得或当前效果全部确认。完整开局牌组、实际扣费/库存变化与其他 UI 布局仍待验证。使用方法见 [出牌数据采集](出牌数据采集.md)。下一步先从现有结算截图补齐最终评价分数、评级与 Vo/Da/Vi，再扩展商店、强化和删除的候选与成本，持续核对：

1. 培育级 `session_id` 贯穿准备、课程、对局和结算，重试/中断续跑作为子段记录；绑定偶像/歌曲卡、流派、等级、可观察到的开局牌组及资源/卡库版本，未读到的字段保留未知。
2. 记录选牌、购物、强化、删除时所有可见候选、价格/资源/限制、实际选择和操作后观察，把不同阶段连到同一会话；同时保存原图与识别证据。
3. 关联最终得分、成功/失败、奖励和中断原因，并检查候选及前后观察的完整性。通过后再针对真实缺口安排补跑。
4. 并行整理可执行卡牌效果与分流派规则评分，先做离线检查，再用代表性账号比较得分；状态不明确时保留现有出牌兜底。LLM 微调或强化学习等待动作、效果与奖励数据可信后再评估。

当前用户无需继续按流派批量刷；下一次培育应在路线采集接好后用于验证，而非单纯增加截图数量。

“流派”、“偶像”和“姿态”是不同维度。冰火局短暂进入全力，可以用于制作全力图标模板，但不能替代全力流派的循环验证。同理，出现少量集中或干劲也不能算已经测过对应主轴。

不必现在遍历每个偶像、等级和卡片组合。先选择能展示目标机制的账号与牌组；等级低、缺少强力卡不会妨碍 HUD 采样，但涉及未解锁卡牌的机制应保持未验证。策略评估阶段再逐步补不同偶像、低/高等级、强化与改造组合。

2026-10-12 的集中/干劲两轮合计 7 段出牌采集、244 张分析帧、230 张可读 HUD，已完成回放。集中效果提升（`setConcentrationEffectBuff`）单独记录百分比与持续回合，不与普通集中层数混用。牌名仍有动画白屏、遮挡和共享前缀造成的未知，不能为了覆盖率而降低统一匹配阈值。当前主要方向已有代表样本，下一阶段先处理现有数据的缺口，再补培育级会话和路线候选采集；无需继续按流派机械重复刷。

## 每轮检查什么

- 开局与结束、至少一个完整的状态增长/消耗循环；关键图标首次出现、数值变化和消失。
- 非凡全力：全力值增长，进入/退出全力，再次蓄积；若出现保留牌/额外出牌机制，同步检查。
- 冰火：强气与温存一/二阶段、热意数值与持续回合、指针预告及其条件文字。
- 好调：好调、绝好调、持续回合；集中：增减和消耗；干劲：干劲、元气和爆发。
- 每个重点状态都保留原截图及 OCR/模板证据。缺失、歧义、遮挡和动画不填零。

只有游戏实际展示了目标机制，这轮才计为该机制的有效样本；没有出现的机制继续列为缺口，无需把相同流程反复跑到固定次数。先回放已有数据，发现缺口后才安排下一轮。

## 完成状态采样之后

先建立各机制的规则评分与可执行卡牌效果，分流派做离线对比，再在代表性账号上测试。完整路线的选牌、购物、强化、删除，还需要培育会话 ID、偶像/等级、开局牌组和候选项记录，不能只依靠出牌截图恢复。

LLM 微调和强化训练留到状态、动作、效果模型与奖励可信之后。识别覆盖率只是数据能读到多少，不是策略正确率。
