# 出牌状态采样计划

采样按缺失机制选择代表场景，不要求每种流派、每个偶像重复跑固定次数。已保存截图能够覆盖的问题先离线回放，确实缺少画面时再补充培育。一次培育不能证明识别稳定或策略具备高分能力。

本文件只记录长期使用的采样方法。具体轮次、会话号、截图路径、计数、实测结论和回归报告保存到 Git 忽略的 `debug/`，不混入业务源码或正式使用说明。

## 采集与验证顺序

1. 确认对局状态、可见 Buff、姿态及计数有对应画面与识别证据，缺失或冲突保留未知。
2. 核对整次培育会话及中断分段，记录偶像、难度、可观察牌组、资源版本、路线候选与实际输入。
3. 关联最终评分、评级、成功/失败和中断原因；检查选牌、购物、强化及删除的候选、成本和操作后观察。
4. 数据能够确认状态、动作与结算后，再比较规则策略。微调或强化学习需要额外确认实际效果和奖励，不能直接将截图观察当作可信轨迹。

会话、采集配置和报告命令见 [出牌数据采集](出牌数据采集.md)。

## 各方向应覆盖的机制

| 方向 | 应保留的证据 | 核验重点 |
| --- | --- | --- |
| 理性·好印象 | 好印象、元气、体力、剩余回合的增长与消耗 | 基础计数、百分比修正、专属与 P 道具触发分别记录 |
| 理性·干劲 | 干劲与元气增长、元气消耗和爆发前后画面 | 不由元气数值推断实际得分或库存 |
| 感性·好调 | 好调、绝好调、持续回合和灰色图标 | 基础持续回合与效果提升百分比分开 |
| 感性·集中 | 集中增长/消耗、效果倍率和额外出牌 | 集中层数与集中效果提升分别核验 |
| 非凡·强气/温存 | 一/二阶段、热意、全力值、姿态切换及预告 | 触发条件与累计值分开，不通过图标颜色猜测姿态 |
| 非凡·全力 | 蓄积、进入/退出全力、再次蓄积及保留卡 | 计数变化不等于已经确认保留牌身份或循环收益 |
| 特殊分支 | 特殊姿态、专属图标及对应触发前后画面 | 未覆盖的机制单独列出，不按相似流派推断 |

流派、偶像和姿态是不同维度。其他流派中出现的通用图标可以复用，但短暂出现某种姿态不能替代该机制完整循环的验证。涉及尚未解锁的卡牌、强化或改造时，应保留未验证状态。

## 每轮检查内容

- 开局与结束、至少一个完整的状态增长/消耗循环；关键图标首次出现、数值变化和消失。
- 原图、OCR/模板证据与输入记录能够关联到同一会话和对应操作。
- 缺失、歧义、遮挡和动画不填零；列表中未出现的状态不自动视为不存在。
- 中断续跑、失败重试、异常终止及结算观察分别留证据。
- 只有游戏实际展示过的机制才计为有效覆盖；未出现的机制保留为采样缺口。

## 策略评估前提

对局截图不足以恢复完整路线。策略评估还需要偶像/等级、开局牌组、候选、成本、实际选择、库存变化及最终结算。识别覆盖率只表示数据可读程度，不能替代策略正确率或实际收益验证。
